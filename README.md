# 🎮 Tic Tac Toe Game

This is a simple Tic Tac Toe game built using:

- HTML
- CSS
- JavaScript

## 📁 Project Structure

tic-tac-toe/
│
├── index.html   → Game structure
├── style.css    → Game design
└── script.js    → Game logic

## 🚀 Features

- Two player game (X and O)
- Win detection
- Draw detection
- Restart button
- Responsive design

## 🛠️ How To Run

1. Download or clone the project
2. Open index.html in your browser
3. Start playing 🎉

## 📸 Game Preview

3x3 grid where players click to place X or O.
